# VALIDA RU

Validador técnico responsive para comparar un TXT base contra uno, dos o tres
despieces cargados simultáneamente. Cada archivo se procesa y reporta por separado.

## Funciones

- Carga manual de TXT base.
- Carga múltiple de Excel `.xls`, `.xlsx` y CSV.
- Detección automática de melamina, herrajes y lacas.
- Normalización de OP con ceros iniciales.
- Compatibilidad de códigos de mueble con extensiones.
- Regla especial `SOPFRE`.
- Reporte independiente con descarga en Excel `.xls` y PDF.
- Diseño unificado en azul petróleo, dorado suave y gris claro.
- Datos de proyecto, resumen general y detalle por cada archivo validado.
- Procesamiento local en el navegador.

## Uso local

Abra `index.html` o sirva la carpeta con cualquier servidor estático.
